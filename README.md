# Dhinahar M — Full Stack Developer Portfolio

> **Live Portfolio**: [dhinahar04.github.io/Portfolio](https://dhinahar04.github.io/Portfolio/)

A premium, cinematic, highly interactive personal portfolio website for **Dhinahar M**, Full Stack Developer & AI Systems Engineer. Designed with a minimal dark-mode aesthetic, editorial typography, Lenis smooth scrolling, custom magnetic cursor, and responsive showcase architecture.

---

## ✨ Features & Visual Highlights

- **Cinematic Preloader**: Smooth 0% to 100% numerical counter with glowing progress indicator and session persistence.
- **Fluid Editorial Typography**: Custom typographic scale utilizing *Syne* (headings), *Plus Jakarta Sans* (body), and *JetBrains Mono* (coordinates & tech tokens).
- **Interactive Hero Stage**: 
  - Dynamic cycling statement ticker (`FULL STACK DEVELOPER`, `BACKEND ENGINEER`, `SOFTWARE DEVELOPER`, `PROBLEM SOLVER`, `AI ENTHUSIAST`).
  - Studio portrait with ambient backlight glow and 3D mouse parallax tilt.
  - Live availability badge, geographic coordinates, and animated scroll indicator.
- **Lenis Smooth Scroll Engine**: Inertial smooth scrolling with spring easing and active navbar section spy.
- **Custom Desktop Cursor**: Magnetic follower dot expanding into a glowing ring on hoverables and a pill displaying `"VIEW ↗"` over project cards.
- **5 Featured Engineering Projects**:
  1. **AI Voice Operating System**: Hands-free natural language computer automation.
  2. **Nebula — AI Workspace Browser**: AI-native workspace analyzing tabs, docs, and live code.
  3. **Phishing Email Detection**: Machine learning & NLP security classifier.
  4. **Flood Detection System**: Deep learning CNN computer vision disaster monitoring.
  5. **Smart Hostel Leave System**: Digital gatepass approval ecosystem with QR verification.
- **Interactive Project Deep Dive Modal**: Detailed architecture highlights, technology pills, and direct repository links.
- **Synthesized Web Audio Feedback**: Subtle procedural audio ticks and pops via browser Web Audio API with a persistent mute toggle.
- **Direct Contact & Confetti Celebrations**: One-click email copy with instant toast confirmation and celebratory particle bursts on resume download.

## 🛠️ Tech Stack

- **Markup & Semantics**: HTML5 with OpenGraph SEO & Accessibility tags
- **Styling**: Vanilla Modern CSS Design System + Tailwind CSS
- **Interactivity**: Vanilla ES6+ Modular JavaScript
- **Smooth Scrolling**: [Lenis](https://github.com/darkroomengineering/lenis)
- **Visuals**: Web Audio API, Canvas Confetti, SVG Noise Filters

## 🚀 Running Locally

Open `index.html` directly in any modern browser, or launch a local preview server:

```bash
# Using Python
python3 -m http.server 3000

# Or using npx serve
npx serve .
```

Visit `http://localhost:3000` to experience the website.
